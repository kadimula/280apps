# sample-apps

Production-ready reference applications for the 280 platform.

In the long run, the apps in this folder should become the canonical, production-ready references: fully incorporating the 280 SDK and properly built for the platform. They are the target end state that a raw test app (see `../test-apps`) is refactored toward.

Each app here should demonstrate correct 280 SDK usage and platform conventions well enough to serve as a reference implementation.

## Apps

- `1-nextjs-with-sdk` — Next.js reference app built on the 280 SDK.
