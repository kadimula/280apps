Architecture explainer

What your code does versus what the Google library does

Your code supplies credentials and asks for spreadsheet data. The Google authentication library performs the JWT and access token work automatically. Google services verify identity, enforce permissions, and return the data.

Sequence diagram

Blue: visible in this app Purple: Google library internals Green: Google services

Ownership map

Visible in this repository

Your app code

  • app/page.tsx calls getTodos().
  • app/actions.ts handles create, toggle, and delete submissions.
  • lib/sheets.ts reads environment variables.
  • lib/sheets.ts constructs GoogleAuth and calls the Sheets methods.
Not shown in your code

Google library internals

  • Build the JWT header and payload.
  • Sign the JWT assertion with the private key.
  • Exchange the assertion for an OAuth access token.
  • Cache the token and replace it when needed.
  • Add the bearer token to the API request.
Runs at Google

Google services

  • Verify the JWT signature using the matching public key.
  • Issue a short lived access token.
  • Validate the access token and spreadsheet scope.
  • Check that the service account can access the sheet.
  • Read or modify spreadsheet rows.

Credentials and generated values

GOOGLE_CLIENT_EMAIL

Visible in your configuration. Identifies the service account and becomes the JWT issuer. It is not the client_id field.

GOOGLE_PRIVATE_KEY

Visible in your server configuration and used only for local signing. It is not placed inside the JWT and is not sent to Google.

JWT assertion

Generated temporarily inside the authentication library. Your app does not create or store it directly.

OAuth access token

Returned by Google and managed by the library. It is sent as a bearer token with Sheets API calls.

Important detail: calling new google.auth.GoogleAuth(...) configures the authentication client. It does not necessarily perform the token exchange at that exact line. The library normally obtains a token lazily when the first authenticated API request requires one.
